# 张恒赵佳豪毕业设计作品H5展示页面

这个静态页面是一份毕业设计作品集展示框架，已集成品牌形象设计、广告设计、包装设计和文创设计板块。

## 文件说明

- `index.html`：页面结构与项目分区。
- `styles.css`：视觉样式与响应式布局。
- `script.js`：导航滚动、动态海报播放与交互逻辑。
- `a1/`：毕业设计素材目录，包含三张海报与三段动态海报视频。

## 使用方式

1. 确认 `a1/海报1.jpg`、`a1/海报2.jpg`、`a1/海报3.jpg` 已存在。
2. 确认 `a1/动态海报1.mp4`、`a1/动态海报2.mp4`、`a1/动态海报3.mp4` 已存在。
3. 如需替换素材，请保持文件名一致，或修改 `index.html` 中对应路径。

## 运行方式

直接打开 `index.html` 即可预览页面。建议使用本地静态服务器，例如：

- 11 插件
- `python -m http.server`（在项目目录下运行）
